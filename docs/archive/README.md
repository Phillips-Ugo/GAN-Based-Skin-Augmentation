# Earlier drafts and process notes

Everything in this directory is kept for reference and is **not current**. These
files were written while preparing an MDPI submission, before the claim ledger
in [`../RESULTS_PROVENANCE.md`](../RESULTS_PROVENANCE.md) was compiled.

They contain figures that the released code does not reproduce, including the
sample-size threshold, the subgroup ablation, and significance tests, as well as
per-class rows whose disease names need correcting. The ledger records which is
which. Drafts are retained rather than deleted so the development of the work
stays traceable.

For the current state, read [`../../README.md`](../../README.md) and
[`../RESULTS_PROVENANCE.md`](../RESULTS_PROVENANCE.md). The current manuscript
is [`../../paper/mdpi_version.tex`](../../paper/mdpi_version.tex).
